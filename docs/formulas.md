# 招聘容量模型 · 公式说明

> 所有"可调"标注的参数后续会在平衡表页面上做成 input 控件，leader 可现场改、看结果实时变化。

---

## 0. 输入符号

### 人员相关
| 符号 | 含义 | 当前默认 | 可调 |
|------|------|----------|------|
| n_MD_init | 仅初诊 MD 数 | 5 | ✓ |
| n_MD_full | 全流程 MD 数 | 3 | ✓ |
| n_NP | NP 数（IP-NP，可开 ADHD 受控药） | 5 | ✓ |
| h_MD | MD 周有效工时（已扣非临床） | 25 h | ✓ |
| h_NP | NP 周有效工时 | 25 h | ✓ |
| u | 利用率（默认医生不按 100% 排满） | 0.85 | ✓ |

### 诊次时长
| 符号 | 含义 | 默认 | 可调 |
|------|------|------|------|
| τ_init | 首诊时长 | 45 min | ✓ |
| τ_drug | 复诊（调药）时长 | 30 min | ✓ |
| τ_fu  | 维持时长 | 15 min | ✓ |

### 周期 / 比例
| 符号 | 含义 | 默认 | 可调 |
|------|------|------|------|
| I_drug | 复诊期 - 患者每多少周看 1 次 | 2 w | ✓ |
| I_fu | 维持期 - 患者每多少周看 1 次 | 2.5 w | ✓ |
| r_tit | 首诊后进入复诊的比例（titration ratio） | 0.60 | ✓ |
| s_init | 全流程 MD 时间投在"初诊"的占比 | 0.50 | ✓ |
| s_ni | 全流程 MD 时间投在"非初诊"的占比 = 1 − s_init | 0.50 | ✓ |

### 患者池快照
| 符号 | 含义 |
|------|------|
| P_init | 当前等待首诊人数 |
| P_drug | 当前在复诊（调药）期的人数 |
| P_fu | 当前在维持期的人数 |

### 需求侧（未来）
| 符号 | 含义 |
|------|------|
| B_w | 第 w 周预期新预约（首诊）数 |
| r_ns | no-show 率 | ✓ |

### 决策
| 符号 | 含义 | 默认 | 可调 |
|------|------|------|------|
| β_MD | MD 端冗余 % | 0.20 | ✓ |
| β_NP | NP 端冗余 % | 0.20 | ✓ |
| L_MD | MD lead time（发 JD → 上岗） | 12 w | ✓ |
| L_NP | NP lead time | 8 w | ✓ |
| W_MD | MD 前瞻窗口 = L_MD | 12 w | ✓ |
| W_NP | NP 前瞻窗口 = L_NP | 8 w | ✓ |

## 1. 单人每周"可用看病分钟数"

```
E(person) = h × 60 × u
```

> 假定个体 availability 已经体现在 h 上（i.e. h 是扣完假期 / 非临床后的工时），所以这里只乘 u。如果想分两层，可以拆 `E = h_contract × 60 × a × u`。

例：MD 默认 `E = 25 × 60 × 0.85 = 1275 min/周/人`

---

## 2. 产能公式（每周分钟）

### 2.1 初诊产能（只能 MD 做）

```
C_init = n_MD_init × E_MD + n_MD_full × E_MD × s_init
```

含义：仅初诊 MD 100% 时间用于首诊；全流程 MD 把 `s_init` 比例的时间贡献给首诊。

### 2.2 非初诊产能（复诊 + 维持合并，MD 全流程 + 全部 NP）

```
C_ni = n_MD_full × E_MD × s_ni + n_NP × E_NP
```

> 因为 NP **可以**同时做复诊和维持，我们不在这一步再细拆 NP 时间给复诊 vs 维持——把它放在分子（总产能），让分母（总需求）也是合并的。

---

## 3. 需求公式（每周分钟）

### 3.1 初诊需求（当周）

```
D_init(w) = B_w × (1 − r_ns) × τ_init
```

未来 W_MD 周累计：
```
D_init_total = Σ_{w=1..W_MD}  D_init(w)
```

### 3.2 非初诊需求（每周 - v0 假设池子在前瞻窗口内不变）

```
D_ni_per_week = (P_drug / I_drug) × τ_drug + (P_fu / I_fu) × τ_fu
```

未来 W_NP 周累计：
```
D_ni_total = D_ni_per_week × W_NP
```

> **进阶**：如果想做"前瞻式"的池子增长（用 r_tit 推），可加：
> ```
> P_drug(t+1) = P_drug(t) + B_{t+1} × (1 − r_ns) × r_tit − drugChurn − transitionsToFu
> P_fu(t+1)   = P_fu(t)   + transitionsToFu − fuChurn
> ```
> v0 先不做，假设池子稳定。这是要不要做的一个 trade-off：精度 vs 复杂度。

---

## 4. 覆盖率（Coverage）—— 与 Excel MVP 对齐

### 4.1 MD 初诊覆盖率（前瞻 W_MD 周）

```
Coverage_MD = (C_init × W_MD) / (D_init_total × (1 + β_MD))
```

> 分母含冗余：覆盖率 1.0 = 刚好覆盖"需求 + 冗余"，超过 1.0 = 有余量。

也可以写成不含冗余的形式（Excel 用的就是这个）：
```
Coverage_MD_raw = (C_init × W_MD) / D_init_total
```
然后用阈值 1.2 / 1.0 判断（见 §5）。

### 4.2 非初诊覆盖率（前瞻 W_NP 周）

```
Coverage_NI_raw = (C_ni × W_NP) / D_ni_total
```

---

## 5. 状态阈值

| Coverage_raw | 状态 | 含义 |
|--------------|------|------|
| ≥ 1 + β | 🟢 够用 | 产能 ≥ 需求 + 冗余 |
| 1 ≤ x < 1 + β | 🟡 紧张 | 能覆盖需求，但已吃掉冗余 → 本周内启动招聘 |
| < 1 | 🔴 不够 | 产能 < 需求 → 立刻发 JD |

β 用 β_MD 或 β_NP，取决于看哪一线。

---

## 6. 缺口（Gap）—— 用于"还差几个人"

### 6.1 缺口分钟数（前瞻窗口内的总缺口）

```
Gap_MD_min = (D_init_total × (1 + β_MD)) − (C_init × W_MD)
Gap_NI_min = (D_ni_total  × (1 + β_NP)) − (C_ni  × W_NP)
```

正数 = 不够，负数 = 有余量。

### 6.2 缺口小时数（Excel 上叫 "Gap Hours"）

```
Gap_MD_hours = Gap_MD_min / 60
Gap_NI_hours = Gap_NI_min / 60
```

### 6.3 建议招聘人数

```
新员工一人每周能贡献 = h_new × 60 × u   (= E_new)
新员工在窗口内能贡献 = E_new × W

招聘人数 = ⌈ Gap_min / (E_new × W) ⌉
```

例：MD 缺口 = 50000 min over 12w，新人 E = 1275 min/w → 一人能贡献 15300 min → 需 ⌈50000/15300⌉ = 4 人。

---

## 7. 招哪种人（决策树）

```
if Coverage_MD < 1 + β_MD:
    招"MD"——可以是仅初诊 MD（成本低，但不能后续 follow up），
            也可以是全流程 MD（贵但灵活）。
            如果同时 NI 也紧张 → 优先全流程 MD（一人两用）

if Coverage_NI < 1 + β_NP:
    招"NP"——首选，成本最低，可做复诊 + 维持
    或招"全流程 MD"——如果 MD 也紧张
```

                                    ↓
        ┌───────────────────────────┴───────────────────────────┐
        ↓                                                         ↓
   ┌──────────────┐                                    ┌──────────────┐
   │  C_init      │                                    │  C_ni        │
   │  (初诊产能)  │                                    │  (非初诊产能)│
   └──────┬───────┘                                    └──────┬───────┘
          │                                                    │
   ┌──────┴───────┐                                    ┌──────┴───────┐
   │ D_init_total │                                    │ D_ni_total   │
   │ (4-12w 总需求)│                                    │ (8w 总需求)  │
   └──────┬───────┘                                    └──────┬───────┘
          │                                                    │
          ↓                                                    ↓

          │                                                    │
          ↓                                                    ↓
   状态 / Gap Hours / 建议人数                        状态 / Gap Hours / 建议人数
```
